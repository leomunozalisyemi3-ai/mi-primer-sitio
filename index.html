Instituto Provincial de la Administración Pública - IPAP

IPAP es una institución pública que se dedica principalmente a capacitar y formar a trabajadores del Estado y también a otros ciudadanos de Río Negro.

Mi carrera

FULL STACK: En esta carrera se aprende a desarrollar aplicaciones y sitios web completos, trabajando tanto en la parte visual como en la programación y el funcionamiento interno.

Materias que cursamos

  • Laboratorio Full Stack
  • Programación
  • Prácticas profesionalizantes
  • Matemática
  • UX/UI

Tecnologías que estamos aprendiendo

  1. HTML
  2. CSS
  3. JavaScript
  4. Git
  5. GitHub

Aprender desarrollo de software es importante porque nos permite crear soluciones tecnológicas y desarrollar habilidades para resolver problemas. Es una formación muy importante para el futuro laboral y requiere práctica.
